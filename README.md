Zentrion Technologies — Pre-Internship JavaScript Assignments

About

This repository contains JavaScript solutions completed as part of the Zentrion Technologies pre-internship training program.

Programs

1. Even or Odd — Checks whether a number is even or odd.
2. Largest of Three Numbers — Finds the largest of three numbers.
3. Reverse a String — Reverses a given string.
4. Palindrome Checker — Checks whether a word is a palindrome.
5. Sum of an Array — Calculates the sum of array elements.

Technologies Used

- JavaScript
- Node.js
